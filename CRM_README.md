## 🛠 Установка

### 1. Установите зависимости

```bash
npm install
# или
pnpm install
```

### 2. Настройте переменные окружения

Создайте файл `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
JWT_SECRET=your_jwt_secret_key
ADMIRAL_API_KEY=your_admiral_api_key
ADMIRAL_API_URL=https://api.admiral.com
```

### 3. Настройте базу данных

1. Откройте Supabase Dashboard
2. Перейдите в SQL Editor
3. Скопируйте и выполните весь код из файла `crm_database_schema.sql`

Это создаст все необходимые таблицы, индексы, триггеры и базовые данные.

## 🗄 Настройка базы данных

### Основные таблицы:

- `crm_users` - Пользователи
- `crm_roles` - Роли
- `crm_clients` - Клиенты
- `crm_deals` - Сделки
- `crm_tasks` - Задачи
- `crm_gps_devices` - GPS устройства
- `crm_finance_income` - Доходы
- `crm_finance_expense` - Расходы
- `crm_finance_payments` - Выплаты
- `crm_finance_bonuses` - Бонусы

### Создание первого администратора

После создания схемы БД, создайте первого администратора через SQL:

```sql
-- Получите ID роли администратора
SELECT id FROM crm_roles WHERE name = 'admin';

-- Создайте пользователя (замените значения)
INSERT INTO crm_users (email, password_hash, full_name, role_id, is_active)
VALUES (
  'admin@example.com',
  'your_hashed_password', -- Используйте функцию хеширования
  'Администратор',
  (SELECT id FROM crm_roles WHERE name = 'admin'),
  true
);
```

**Важно:** Для хеширования пароля используйте функцию `hashPassword` из `lib/crm-auth.ts` или создайте пользователя через API регистрации.

## 📡 API Endpoints

### Авторизация

- `POST /api/crm/auth/register` - Регистрация
- `POST /api/crm/auth/login` - Вход
- `GET /api/crm/auth/verify` - Проверка токена

### Сделки

- `GET /api/crm/deals` - Список сделок
- `POST /api/crm/deals` - Создать сделку
- `GET /api/crm/deals?status=completed` - Фильтр по статусу
- `GET /api/crm/deals?manager_id=uuid` - Фильтр по менеджеру

### Задачи

- `GET /api/crm/tasks` - Список задач
- `POST /api/crm/tasks` - Создать задачу
- `PATCH /api/crm/tasks/[id]` - Обновить задачу
- `GET /api/crm/tasks?assigned_to=uuid` - Задачи монтажника
- `GET /api/crm/tasks?status=in_progress` - Фильтр по статусу

### GPS

- `GET /api/crm/gps` - Список устройств
- `POST /api/crm/gps` - Добавить устройство
- `POST /api/crm/gps/[id]/command` - Отправить команду

### Финансы

- `GET /api/crm/finance` - Финансовые данные (только админ)

### Дашборд

- `GET /api/crm/dashboard` - Данные дашборда (зависит от роли)

- ✅ Настройка бонусов

### Менеджер продаж (manager)

- ✅ Фиксация продаж
- ✅ Автоматический расчет бонуса
- ✅ Загрузка документов
- ✅ Создание заявок монтажникам

- ❌ Доступ к финансам
